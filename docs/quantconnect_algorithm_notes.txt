1. CORE ARCHITECTURE & ENGINE
================================================================================

ENGINE: LEAN (open-source, C# core, Python 3.11 via Python.Net)
- All algorithms subclass QCAlgorithm
- Event-driven streaming: data arrives in strict time order
- Time Frontier prevents look-ahead bias - you only see data up to current time
- Timeslice/Slice: all data at a moment bundled into one Slice object

SYMBOL OBJECTS (CRITICAL FOR RELIABILITY):
- Symbol objects are permanent identifiers that persist even when tickers change
- Always store and use Symbol objects, NOT ticker strings
- LEAN uses map files to track ticker changes automatically

SECURITY OBJECT:
- Models an individual asset with price, holdings, reality models, market hours
- Access via self.securities[symbol]
- Properties: price, holdings, is_tradable, exchange, symbol_properties

DATA FORMATS:
- TradeBar: OHLCV period data (open, high, low, close, volume)
- QuoteBar: bid/ask spread data (more accurate for fills)
- Tick: point-in-time trade or quote (most granular, most overhead)

RESOLUTIONS (choose carefully for cost/performance balance):
- TICK: Maximum granularity, very high memory/CPU cost
- SECOND: High frequency, significant overhead
- MINUTE: Default for equity - good balance of detail vs cost
- HOUR: Good for daily rebalancing strategies
- DAILY: Lowest overhead, best for fundamental/long-term strategies

FILL FORWARD (default=True):
- When True: uses last known price when no new data point is available
- Prevents NaN gaps in indicators
- Disable only when you specifically need to detect missing data

```python
class MyAlgorithm(QCAlgorithm):
    def initialize(self) -> None:
        self.set_start_date(2020, 1, 1)
        self.set_end_date(2024, 12, 31)
        self.set_cash(100000)

    def on_data(self, slice: Slice) -> None:
        if self.is_warming_up: return
        bar = slice.bars.get(self._symbol)
        if bar is None or not self._sma.is_ready: return
        # trading logic here

    def on_order_event(self, order_event: OrderEvent) -> None:
        # handle fills, cancellations, etc.
        pass
```

KEY EVENT HANDLERS:
- initialize(): One-time setup. Add securities, indicators, schedules
- on_data(slice): Called every time step. Main trading logic
- on_order_event(order_event): Called when order status changes
- on_securities_changed(changes): Called when universe changes
- on_splits(splits): Handle stock splits
- on_dividends(dividends): Handle dividend payments
- on_symbol_changed_events(events): Handle ticker changes
- on_delistings(delistings): Handle delisted stocks

```python
def on_splits(self, splits: Splits) -> None:
    split = splits.get(self._symbol)
    if split and split.type == SplitType.SPLIT_OCCURRED:
        # Reset and re-warm indicators after split
        self._ema.reset()
        history = self.history[TradeBar](
            self._symbol, self._ema.warm_up_period,
            data_normalization_mode=DataNormalizationMode.SCALED_RAW)
        for bar in history:
            self._ema.update(bar.end_time, bar.close)

def on_dividends(self, dividends: Dividends) -> None:
    dividend = dividends.get(self._symbol)
    if dividend:
        # Reinvest dividends
        total = dividends[self._symbol].distribution * self.portfolio[self._symbol].quantity
        qty = np.floor(total / self._symbol.price)
        if qty: self.market_order(self._symbol, qty)

def on_delistings(self, delistings: Delistings) -> None:
    delisting = delistings.get(self._symbol)
    if delisting and delisting.type == DelistingType.WARNING:
        # Exit before forced liquidation
        qty = self.portfolio[self._symbol].quantity
        if qty != 0:
            self.market_on_open_order(self._symbol, -qty)
```

```python
def _fundamental_filter(self, fundamental: List[Fundamental]) -> List[Symbol]:
    # Filter for quality stocks with sufficient liquidity
    filtered = [
        x for x in fundamental
        if x.has_fundamental_data
        and x.price > 5                    # avoid penny stocks
        and x.dollar_volume > 10_000_000   # minimum liquidity
        and x.market_cap > 1_000_000_000   # large/mid cap only
    ]
    # Return top N by dollar volume (survivorship bias warning: use point-in-time data)
    return [x.symbol for x in sorted(filtered,
        key=lambda x: x.dollar_volume, reverse=True)[:500]]
```

```python
def _rebalance(self):
    symbols_by_sector = {}
    for symbol in self._universe.selected:
        equity = self.securities[symbol]
        if not equity.price: continue
        sector = equity.fundamentals.asset_classification.morningstar_sector_code
        symbols_by_sector.setdefault(sector, []).append(symbol)

    targets = []
    sector_count = len(symbols_by_sector)
    for symbols in symbols_by_sector.values():
        weight = 1 / sector_count / len(symbols)
        targets.extend([PortfolioTarget(s, weight) for s in symbols])
    self.set_holdings(targets, liquidate_existing_holdings=True)
```

ORDER TYPES (choose for cost-effectiveness):
- Market Order: Immediate fill, worst price - use sparingly
- Limit Order: Fixed price, may not fill - best for cost control
- Market On Open (MOO): Fills at official open price - good for rebalancing
- Market On Close (MOC): Fills at official close price
- Stop Market: Trigger price then market - for stop losses
- Stop Limit: Trigger price then limit - safer stop losses
- Trailing Stop: Dynamic stop loss

```python
def on_order_event(self, order_event: OrderEvent) -> None:
    if order_event.status == OrderStatus.FILLED:
        self.log(f"Filled: {order_event.symbol} qty={order_event.fill_quantity} price={order_event.fill_price}")

        if "symbol changed event" in ticket.tag:
```

CUSTOM INDICATORS:
```python
class CustomSMA(PythonIndicator):
    def __init__(self, period):
        self.name = f"SMA({period})"
        self.period = period
        self.queue = deque(maxlen=period)
        self.value = 0

    def is_ready(self):
        return len(self.queue) >= self.period

    def update(self, input):
        self.queue.append(input.value)
        self.value = sum(self.queue) / len(self.queue)
        return self.is_ready()
```

--- CROSS-SECTIONAL MOMENTUM (12-1 Month Lookback) ---
```python
def _rebalance(self):
    momentum = {}
    for symbol in self.active_securities.keys():
        history = list(self.history[TradeBar](symbol, 280, Resolution.DAILY))
        if len(history) < 252: continue
        end_price = history[-22].close   # skip most recent month (reversal effect)
        start_price = history[0].close
        if start_price == 0: continue
        momentum[symbol] = float(end_price / start_price - 1)

    top_count = max(1, len(momentum) // 10)  # top decile
    winners = sorted(momentum, key=momentum.get, reverse=True)[:top_count]
    weight = 1.0 / len(winners)
    for symbol in winners:
        self.set_holdings(symbol, weight)
    for holding in self.portfolio.values():
        if holding.invested and holding.symbol not in winners:
            self.liquidate(holding.symbol)
```

```python
    if price is None: return
    close = price.close
    if not self.portfolio[self._spy].invested:

    elif self.portfolio[self._spy].is_long:

            self.liquidate(self._spy)  # exit at mean
```

18. BIASES TO AVOID (PROFITABLE)
================================================================================

LOOK-AHEAD BIAS (most dangerous):
- Never use future data in signals - LEAN's Time Frontier prevents this
- Watch for: using adjusted data without proper normalization
- Watch for: training ML models on the full dataset before splitting

SURVIVORSHIP BIAS:
- Your universe should include delisted companies
- QuantConnect data includes delisted stocks
- Don't filter universe to only currently-traded stocks

OVERFITTING:
- Don't optimize parameters on the same data you'll trade
- Walk-forward optimization only
- Use out-of-sample validation
- Fewer parameters = more robust strategy

DATA DREDGING / P-HACKING:
- Form hypothesis FIRST, then test
- Don't scan hundreds of indicators to find what worked
- Apply Bonferroni correction if testing multiple strategies

12 BEHAVIORAL BIASES TO AVOID IN STRATEGY DESIGN:
1. Anchoring: Don't anchor to entry price for exit decisions
2. Availability: Recent dramatic events shouldn't dominate your model
3. Confirmation: Test against your thesis, not for it
4. Disposition Effect: Don't hold losers too long or sell winners too early
5. Endowment: Don't value positions you own higher just because you own them
6. Herd Mentality: Don't follow crowded trades
7. Loss Aversion: Losses and gains of equal size should matter equally
8. Narrative Fallacy: Don't post-hoc rationalize patterns as causal
9. Overconfidence: Assume your backtest will perform worse live
10. Recency: Long historical testing periods matter
11. Status Quo: Don't avoid rebalancing due to inertia
12. Sunk Cost: Exit losing positions regardless of entry price

TRANSACTION COST NEGLECT:
- Always model realistic fees (IB: $0.005/share or 0.35% for US equity)
- Include slippage especially for illiquid securities
- High-frequency strategies are particularly sensitive to transaction costs

```python
        self.universe_settings.asynchronous = True
        self.add_universe(self._filter)
        self.schedule.on(self.date_rules.month_start("SPY"),
            self.time_rules.after_market_open("SPY", 30), self._rebalance)

    def _filter(self, fundamental):
        return [x.symbol for x in sorted(
            [f for f in fundamental if f.has_fundamental_data
             and f.price > 5 and f.dollar_volume > 5_000_000],
            key=lambda x: x.dollar_volume, reverse=True)[:200]]

    def _rebalance(self):
        momentum = {}
        for symbol in self.active_securities.keys():
            hist = list(self.history[TradeBar](symbol, 280, Resolution.DAILY))
            if len(hist) < 252: continue
            start, end = hist[0].close, hist[-22].close
            if start > 0: momentum[symbol] = end / start - 1
        if not momentum: return
        top = sorted(momentum, key=momentum.get, reverse=True)[:max(1, len(momentum)//10)]
        w = 1.0 / len(top)
        targets = [PortfolioTarget(s, w) for s in top]
        self.set_holdings(targets, liquidate_existing_holdings=True)

    def on_data(self, slice: Slice) -> None:
        pass  # logic is in scheduled event
```

```python
    funding = actual_rate * position_value / holding.security_price
    # Adjust position size by the funding amount (round to lot size)
    quantity = -funding // self._lot_size * self._lot_size
    if quantity:
        self.market_order(self._symbol, quantity)
```

```python
def _get_limit_price(self, security, target_price, round_up=True):
    params = GetMinimumPriceVariationParameters(security, target_price)
    pip = security.price_variation_model.get_minimum_price_variation(params)
    return (int(target_price / pip) + int(round_up)) * pip
```

ORDER EVENT HANDLER — react to every state change:
```python
def on_order_event(self, order_event: OrderEvent) -> None:
    if order_event.status == OrderStatus.FILLED:
        self.log(f"FILL {order_event.symbol}: qty={order_event.fill_quantity} "
                 f"@ {order_event.fill_price:.4f}, fee={order_event.order_fee}")

    elif order_event.status == OrderStatus.PARTIALLY_FILLED:
        remaining = order_event.quantity - order_event.fill_quantity
        self.log(f"Partial fill, {remaining} remaining")

    elif order_event.status == OrderStatus.CANCELED:
        ticket = self.transactions.get_order_ticket(order_event.order_id)
        if ticket and "symbol changed event" in (ticket.tag or ""):
            # Resubmit after rollover/ticker change
```

```python
class MyRiskManagementModel(RiskManagementModel):
    def __init__(self, max_drawdown=0.05, max_position_weight=0.20):
        self._max_dd = max_drawdown
        self._max_weight = max_position_weight

    def manage_risk(self, algorithm, targets):
        new_targets = []
        for holding in algorithm.portfolio.values():
            if not holding.invested: continue
            # Per-security drawdown stop
            if holding.unrealized_profit_percent < -self._max_dd:
                new_targets.append(PortfolioTarget(holding.symbol, 0))
            # Position concentration limit
            weight = abs(holding.holdings_value / algorithm.portfolio.total_portfolio_value)
            if weight > self._max_weight:
                new_targets.append(PortfolioTarget(holding.symbol,
                    self._max_weight * (1 if holding.is_long else -1)))
        return new_targets
```

MANUAL STOP LOSS PATTERNS (Classic Algorithm style):
```python
def on_data(self, slice: Slice) -> None:
    for symbol in list(self.portfolio.keys()):
        holding = self.portfolio[symbol]
        if not holding.invested: continue

        # Hard stop loss
        if holding.unrealized_profit_percent < -0.05:
            self.liquidate(symbol, tag="stop-loss 5%")

        # Trailing stop (track peak price manually)
        current_price = self.securities[symbol].price
        self._peak[symbol] = max(self._peak.get(symbol, current_price), current_price)
        if holding.is_long and current_price < self._peak[symbol] * 0.95:
            self.liquidate(symbol, tag="trailing stop 5%")

        # Take profit
        if holding.unrealized_profit_percent > 0.20:
            self.liquidate(symbol, tag="take profit 20%")

        # Time-based exit
        if (self.time - self._entry_time.get(symbol, self.time)).days > 30:
            self.liquidate(symbol, tag="time exit 30d")
```

```python
def initialize(self):
    self._peak_value    = 0
    self._max_dd_limit  = 0.15     # 15% drawdown halts trading
    self._trading_halted = False

def on_data(self, slice):

    # ... normal strategy logic ...
```

POSITION CONCENTRATION LIMITS:
```python
def _check_concentration(self, symbol, target_weight):
    max_single = 0.15          # 15% max per position
    max_sector = 0.35          # 35% max per sector

    # Cap single position
    target_weight = min(abs(target_weight), max_single) * (1 if target_weight >= 0 else -1)

    # Cap sector exposure
    sector = self.securities[symbol].fundamentals.asset_classification.morningstar_sector_code
    current_sector_exposure = sum(
        abs(self.portfolio[s].holdings_value) / self.portfolio.total_portfolio_value
        for s in self.portfolio.keys()
        if self.portfolio[s].invested
        and self.securities[s].fundamentals
        and self.securities[s].fundamentals.asset_classification.morningstar_sector_code == sector
    )
    if current_sector_exposure + abs(target_weight) > max_sector:
        target_weight = max(0, max_sector - current_sector_exposure) * (1 if target_weight >= 0 else -1)

    return target_weight
```

```python
def _kelly_size(self, win_rate, avg_win, avg_loss):
    if avg_loss == 0: return 0.0
    b = avg_win / avg_loss
    kelly = win_rate - (1 - win_rate) / b
    return max(0, min(kelly * 0.5, 0.20))   # half-Kelly, capped at 20%
```

```python
# Compute rolling correlation using history
def _get_correlation(self, sym_a, sym_b, lookback=60):
    hist = self.history([sym_a, sym_b], lookback, Resolution.DAILY)
    returns = hist['close'].unstack(0).pct_change().dropna()
    if sym_a in returns and sym_b in returns:
        return returns[sym_a].corr(returns[sym_b])
    return 0.0

# Only enter new position if correlation with existing < 0.7
for existing_symbol in self.portfolio.keys():
    if self.portfolio[existing_symbol].invested:
        if self._get_correlation(symbol, existing_symbol) > 0.7:
            return   # skip highly correlated position
```

- Always define max drawdown before deploying any strategy
- Trailing stops outperform fixed stops in trending markets
- Half-Kelly sizing is safer than full-Kelly (accounts for estimation error)
- Never let a single position exceed 15-20% of portfolio
- Never let a single sector exceed 30-35% of portfolio
- Halt all new entries (not just liquidate) if portfolio drawdown > 15%
- In live trading: set real broker stop orders as backup to algo stops

```python
class MyMomentumAlphaModel(AlphaModel):
    def __init__(self, lookback=252, top_n=20):
        self._lookback = lookback
        self._top_n    = top_n

    def update(self, algorithm: QCAlgorithm, slice: Slice) -> List[Insight]:
        insights = []
        scores = {}
        for symbol in algorithm.active_securities.keys():
            hist = list(algorithm.history[TradeBar](symbol, self._lookback + 22, Resolution.DAILY))
            if len(hist) < self._lookback: continue
            momentum = hist[-22].close / hist[0].close - 1   # skip last month
            scores[symbol] = momentum

        if not scores: return []
        top = sorted(scores, key=scores.get, reverse=True)[:self._top_n]
        for symbol in algorithm.portfolio.keys():
            if algorithm.portfolio[symbol].invested and symbol not in top:
                insights.append(Insight.price(symbol, timedelta(1), InsightDirection.FLAT))
        for symbol in top:
            insights.append(Insight.price(symbol, timedelta(days=30),
                InsightDirection.UP, magnitude=scores[symbol], confidence=0.7))
        return insights

    def on_securities_changed(self, algorithm, changes):
        pass   # no per-security state needed here
```

```python
class RankWeightedPortfolioConstructionModel(PortfolioConstructionModel):
    def create_targets(self, algorithm: QCAlgorithm,
                       insights: List[Insight]) -> List[PortfolioTarget]:
        # Sort insights by confidence descending
        active = [i for i in insights if i.direction != InsightDirection.FLAT]
        active.sort(key=lambda i: i.confidence or 0, reverse=True)
        n = len(active)
        if n == 0:
            # Flat all positions
            return [PortfolioTarget(s, 0)
                    for s in algorithm.portfolio.keys()
                    if algorithm.portfolio[s].invested]
        # Linear rank weights sum to 1
        weights = [(n - i) / sum(range(1, n + 1)) for i in range(n)]
        targets = [PortfolioTarget(i.symbol, w * (1 if i.direction == InsightDirection.UP else -1))
                   for i, w in zip(active, weights)]
        # Exit positions for symbols not in active insights
        active_symbols = {i.symbol for i in active}
        for s in algorithm.portfolio.keys():
            if algorithm.portfolio[s].invested and s not in active_symbols:
                targets.append(PortfolioTarget(s, 0))
        return targets
```

```python
class LimitOrderExecutionModel(ExecutionModel):
    def execute(self, algorithm: QCAlgorithm, targets: List[PortfolioTarget]) -> None:
        for target in targets:
            symbol    = target.symbol
            quantity  = target.quantity
            security  = algorithm.securities[symbol]
            current_q = algorithm.portfolio[symbol].quantity

            order_qty = quantity - current_q
            if order_qty == 0: continue

            # Use limit order slightly inside the spread
            price = security.ask_price if order_qty > 0 else security.bid_price
            # 0.1% better than market
            limit_price = price * (0.999 if order_qty > 0 else 1.001)
            algorithm.limit_order(symbol, order_qty, limit_price, tag="LimitExecution")

    def on_securities_changed(self, algorithm, changes):
        # Cancel open orders for removed securities
        for removed in changes.removed_securities:
            algorithm.transactions.cancel_open_orders(removed.symbol)
```

32. SUPPLY & DEMAND ZONES — PRICE ACTION STRATEGY
================================================================================

CONCEPT:
  Supply and Demand (S&D) is a price action strategy rooted in institutional order
  flow. Large institutions cannot fill entire orders at once — they leave unfilled
  orders at price levels where they previously engaged. When price returns to those
  levels, remaining orders re-trigger, causing price to bounce.

  DEMAND ZONE — Area where strong buying occurred (price left rapidly upward).
                When price returns → buy (unfilled buy orders re-engage).
  SUPPLY ZONE  — Area where strong selling occurred (price left rapidly downward).
                When price returns → sell/short (unfilled sell orders re-engage).

ZONE FORMATION PATTERNS:
  Pattern                  | Meaning
  -------------------------|----------------------------------------------------
  Rally-Base-Rally (RBR)   | Demand zone: uptrend, tight base, uptrend continues
  Drop-Base-Rally  (DBR)   | Demand zone: downtrend, tight base, reversal upward
  Rally-Base-Drop  (RBD)   | Supply zone: uptrend, tight base, reversal downward
  Drop-Base-Drop   (DBD)   | Supply zone: downtrend, tight base, downtrend continues

  KEY DEFINITIONS:
    Rally  = strong bullish move (body > 1.5× avg candle body)
    Drop   = strong bearish move (body > 1.5× avg candle body)
    Base   = tight consolidation (1–3 small candles, body < 50% of avg body)
    Impulse= the candle(s) moving sharply away from the base

ZONE BOUNDARIES:
  DEMAND ZONE:
    Top edge    = high of the highest base candle
    Bottom edge = low of the lowest base candle
    Stop loss   = 10–15% below bottom edge (below the zone)
    Target      = nearest supply zone above (minimum 2:1 R:R)

  SUPPLY ZONE:
    Top edge    = high of the highest base candle
    Bottom edge = low of the lowest base candle
    Stop loss   = 10–15% above top edge (above the zone)
    Target      = nearest demand zone below (minimum 2:1 R:R)

ZONE QUALITY FILTERS (rank zones by these):
  1. FRESHNESS   — Zone must be unvisited since formation (price has not re-entered)
                   A zone is consumed once price closes inside it
  2. IMPULSE STR — Move out of base must be > 3× height of the base itself
  3. BASE TIGHT  — Fewer base candles = stronger (1–2 preferred, max 3)
  4. TIME        — Older zones are weaker (prefer zones < 20 bars old for intraday,
                   < 60 bars for daily)
  5. HIGHER TF   — Daily zone > 4H zone > 1H zone (higher = more institutional)
  6. VIRGIN      — First touch of a zone is highest probability; second touch weaker

CODE: IDENTIFY DEMAND ZONES (daily bars)
```python
import numpy as np

def _identify_demand_zones(self, symbol, lookback=100):
    bars = self.history(symbol, lookback, Resolution.DAILY)
    if bars is None or bars.empty or len(bars) < 5:
        return []

    closes = bars['close'].values
    highs  = bars['high'].values
    lows   = bars['low'].values
    opens  = bars['open'].values
    bodies = np.abs(closes - opens)
    avg_body = np.mean(bodies)

    zones = []
    for i in range(2, len(closes) - 2):
        body_i = bodies[i]

        # Is candle i a BASE? (small body relative to average)
        if body_i > avg_body * 0.5:
            continue

        # Is the NEXT candle(s) a strong bullish impulse?
        impulse_body = bodies[i + 1]
        impulse_pct  = (closes[i + 1] - opens[i + 1]) / opens[i + 1]

        if impulse_pct > 0.015 and impulse_body > avg_body * 1.5:
            zone_top    = max(opens[i], closes[i], highs[i])
            zone_bottom = min(opens[i], closes[i], lows[i])
            impulse_size = abs(closes[i + 1] - opens[i + 1])
            zone_height  = zone_top - zone_bottom if zone_top > zone_bottom else 0.001

            if impulse_size < zone_height * 3:
                continue   # impulse not strong enough

            # Check zone is FRESH (price never re-entered after formation)
            future_lows = lows[i + 2:]
            if any(l < zone_top for l in future_lows):
                continue   # zone already consumed

            zones.append({
                'top':       zone_top,
                'bottom':    zone_bottom,
                'formed_idx': i,
                'impulse':   impulse_pct,
                'age':       len(closes) - i   # bars since zone formed
            })

    # Sort: freshest and strongest first
    zones.sort(key=lambda z: (-z['impulse'], z['age']))
    return zones
```

CODE: ENTRY SIGNAL — PRICE AT DEMAND ZONE WITH CONFIRMATION
```python
def _check_sd_entry(self, symbol):
    price  = self.securities[symbol].price
    zones  = self._identify_demand_zones(symbol, lookback=120)

    for zone in zones:
        # Price is touching or inside demand zone
        if zone['bottom'] * 0.99 <= price <= zone['top'] * 1.005:
            # Confirmation: current candle closes above zone top (bounce confirmed)
            bars = self.history(symbol, 2, Resolution.DAILY)
            if bars is None or bars.empty:
                return None
            last_close = bars['close'].values[-1]
            if last_close > zone['top']:
                risk        = zone['top'] - zone['bottom']
                stop_price  = zone['bottom'] - risk * 0.15
                target_price = zone['top'] + risk * 2.5   # 2.5:1 R:R
                return {
                    'signal':  'LONG',
                    'entry':   price,
                    'stop':    stop_price,
                    'target':  target_price,
                    'zone':    zone
                }
    return None
```

CODE: POSITION SIZING FOR S&D (risk-based)
```python
def _sd_position_size(self, symbol, entry_price, stop_price, risk_pct=0.01):
    # Risk 1% of portfolio per trade
    portfolio_value = self.portfolio.total_portfolio_value
    risk_dollars    = portfolio_value * risk_pct
    risk_per_share  = abs(entry_price - stop_price)
    if risk_per_share == 0:
        return 0
    shares = int(risk_dollars / risk_per_share)
    # Cap at 10% portfolio weight
    max_shares = int(portfolio_value * 0.10 / entry_price)
    return min(shares, max_shares)
```

CODE: FULL S&D ENTRY HANDLER (call from scheduled function or on_data)
```python
def _scan_sd_signals(self):
    if self.is_warming_up or self._trading_halted:
        return

    for symbol in self.active_securities.keys():
        if symbol.security_type != SecurityType.EQUITY:
            continue
        if self.portfolio[symbol].invested:
            continue   # already have a position

        signal = self._check_sd_entry(symbol)
        if not signal:
            continue

        qty = self._sd_position_size(
            symbol, signal['entry'], signal['stop'], risk_pct=0.01)
        if qty <= 0:
            continue

        # Entry limit order at zone top (confirmed bounce)
        ticket = self.limit_order(
            symbol, qty, signal['entry'] * 1.001,
            tag=f"sd-demand-entry")

        # Attach stop loss
        stop_ticket = self.stop_market_order(
            symbol, -qty, signal['stop'],
            tag=f"sd-stop-loss")

        # Store target for take-profit management
        self._sd_targets[symbol] = signal['target']
        self._sd_stops[symbol]   = stop_ticket.order_id

    self.log(f"S&D scan complete — {sum(1 for h in self.portfolio.values() if h.invested)} positions")
```

CODE: TAKE-PROFIT AND ZONE INVALIDATION MANAGEMENT
```python
def on_data(self, slice):
    if self.is_warming_up:
        return

    for symbol, target in list(self._sd_targets.items()):
        if not self.portfolio[symbol].invested:
            self._sd_targets.pop(symbol, None)
            self._sd_stops.pop(symbol, None)
            continue

        price = self.securities[symbol].price

        # Take profit at target
        if price >= target:
            self.liquidate(symbol, tag="sd-take-profit")
            self._sd_targets.pop(symbol, None)
            # Cancel associated stop order
            stop_id = self._sd_stops.pop(symbol, None)
            if stop_id:
                self.transactions.cancel_order(stop_id)
```

INVALIDATION RULES (when to cancel/skip a zone):
  - Zone is consumed: price closed INSIDE the zone without bouncing
  - News event: earnings, FDA decision, macro shock during zone approach
  - Spread too wide: bid/ask spread > 0.5% (indicates low liquidity at zone)

  Risk per trade     : 0.5–1.0% of portfolio per entry
  R:R minimum        : 2:1 (target must be at least 2× the stop distance)
  Max concurrent S&D : 5 positions (to limit correlated zone trades)
  Zone age limit     : 60 daily bars
  Confirmation candle: Required — do NOT enter on first touch without confirmation
  First touch only   : Highest probability; second touch acceptable at 50% size

KEY S&D RULES:
  SD1. Never enter on first touch without confirmation — wait for a bounce candle
  SD2. Stop goes BELOW zone (demand) or ABOVE zone (supply), never inside
  SD3. Fresh (unvisited) zones only — consumed zones have lower probability
  SD4. Higher timeframe zones take priority over lower timeframe zones
  SD5. Cancel open S&D entry orders if price trades through zone without bouncing
  SD6. Never trade S&D zones against a strong trending market (e.g., SPY trending down = avoid demand zones)
  SD7. Only one order per zone — do not pyramid into S&D setups
  SD8. Log zone details on every scan for debugging and audit trail

33. WYCKOFF METHOD — ACCUMULATION, DISTRIBUTION & MARKET PHASES
================================================================================

CONCEPT:
  Developed by Richard Wyckoff (1930s). Studies the footprints of large
  institutional operators ("Composite Man") through price and volume analysis.
  The market moves in cycles — large players accumulate quietly, mark up prices,
  distribute at the top, then mark down. Identifying the phase tells you whether
  to buy, hold, or sell.

THREE WYCKOFF LAWS:
  1. Law of Supply & Demand   — Price rises when demand > supply, falls when supply > demand
  2. Law of Cause & Effect    — The size of the subsequent move = size of the accumulation/distribution base
                                (wider trading range = bigger markup/markdown ahead)
  3. Law of Effort vs Result  — Volume (effort) should confirm price movement (result).
                                Divergence = warning sign.
                                High volume + small price move = absorption (opposing side is strong)
                                Low volume + large price move = easy movement (no opposition)

THE WYCKOFF PRICE CYCLE:
  Accumulation → Markup → Distribution → Markdown → (repeat)

  ACCUMULATION  : Institutions quietly buy from retail (sideways, choppy range)
  MARKUP        : Price trends up; public joins late
  DISTRIBUTION  : Institutions quietly sell to retail (sideways, choppy range at top)
  MARKDOWN      : Price trends down; retail panics, sells to institutions again


================================================================================
ACCUMULATION SCHEMATIC — KEY EVENTS
================================================================================

  Event | Name                   | Description
  ------|------------------------|--------------------------------------------------
  PS    | Preliminary Support    | First sign of buying after downtrend; volume increases but not climactic
  SC    | Selling Climax         | Panic selling; wide bar, high volume, closes off lows → bottoming signal
  AR    | Automatic Rally        | Price bounces from SC; establishes top of trading range
  ST    | Secondary Test         | Price retests SC area; LOWER volume = bullish (less supply)
  JAC   | Jump Across the Creek  | Price breaks above AR on high volume (creek = resistance)
  Spring| Spring                 | Price briefly dips BELOW SC/PS (shakes out weak hands), then recovers quickly
  LPS   | Last Point of Support  | Higher low after Spring; reduced supply; re-entry point
  SOS   | Sign of Strength       | Strong rally on HIGH volume, breaks through AR — markup about to begin
  BU    | Back Up (to the Edge)  | Price returns to broken resistance (now support) before final markup

  ACCUMULATION SEQUENCE:
    PS → SC → AR → ST → (Spring) → LPS → SOS → BU → Markup

  TRADING SIGNALS FROM ACCUMULATION:
    BUY 1: Spring + recovery on lower volume (trap confirmed)
    BUY 2: LPS (higher low on low volume) — conservative entry
    BUY 3: SOS breakout above AR on high volume — aggressive entry
    BUY 4: BU pullback to former resistance — lowest risk entry, highest probability


================================================================================
DISTRIBUTION SCHEMATIC — KEY EVENTS
================================================================================

  Event | Name                      | Description
  ------|---------------------------|--------------------------------------------------
  PSY   | Preliminary Supply        | First resistance after uptrend; increased volume
  BC    | Buying Climax             | Euphoric buying; wide bar, high volume, closes off highs → topping signal
  AR    | Automatic Reaction        | Price drops from BC; establishes bottom of trading range
  ST    | Secondary Test            | Price retests BC area on LOWER volume = bearish (less demand)
  SOW   | Sign of Weakness          | Down move on HIGH volume, breaks through AR — markdown imminent
  LPSY  | Last Point of Supply      | Lower high on weak volume (weak bounce) — short entry
  UTAD  | Upthrust After Dist.      | Fake breakout ABOVE BC to trap late longs before markdown

  DISTRIBUTION SEQUENCE:
    PSY → BC → AR → ST → (UTAD) → SOW → LPSY → Markdown

  TRADING SIGNALS FROM DISTRIBUTION:
    SHORT 1: UTAD + rejection candle (fake breakout trap)
    SHORT 2: LPSY (lower high on weak volume) — conservative short entry
    SHORT 3: SOW breakdown below AR on high volume — aggressive short
    SHORT 4: Rally back to AR (now resistance) — lowest risk short


================================================================================
VOLUME SPREAD ANALYSIS (VSA) — READING WYCKOFF WITH VOLUME
================================================================================

  Pattern                  | Price Spread | Volume  | Meaning
  -------------------------|--------------|---------|---------------------------
  Selling Climax           | Wide down    | Very Hi | Institutions absorbing supply (bullish)
  Buying Climax            | Wide up      | Very Hi | Institutions distributing (bearish)
  No Supply                | Narrow down  | Low     | Sellers exhausted → bullish
  No Demand                | Narrow up    | Low     | Buyers exhausted → bearish
  Effort to Rise           | Wide up      | High    | Demand in control (bullish)
  Effort to Fall           | Wide down    | High    | Supply in control (bearish)
  Absorption (Accumulation)| Narrow       | High    | Selling absorbed by institutions (bullish)
  Absorption (Distribution)| Narrow       | High    | Buying absorbed by institutions (bearish)
  Stopping Volume          | Down bar     | Very Hi | Climactic selling — bottom near
  Upthrust                 | Up bar       | Low     | Weak breakout → reversal likely

  RULE: Volume confirms direction.
    - High volume on advance = healthy trend
    - High volume on decline into accumulation = climactic (bullish reversal)
    - Low volume on advance near resistance = no demand (distribution warning)
    - Low volume on decline after breakout = no supply (markup continuation)

```python
def _detect_selling_climax(self, bars, lookback=20):
    closes  = bars['close'].values
    lows    = bars['low'].values
    highs   = bars['high'].values
    opens   = bars['open'].values
    volumes = bars['volume'].values
    bodies  = np.abs(closes - opens)
    avg_vol  = np.mean(volumes[-lookback:])
    avg_body = np.mean(bodies[-lookback:])

    events = []
    for i in range(lookback, len(closes)):
        is_down_bar   = closes[i] < opens[i]
        wide_spread   = bodies[i] > avg_body * 2.0
        high_volume   = volumes[i] > avg_vol * 2.0
        closes_off_low = (closes[i] - lows[i]) > bodies[i] * 0.3  # not at the low

        if is_down_bar and wide_spread and high_volume and closes_off_low:
            events.append({
                'type':  'SC',
                'index': i,
                'price': closes[i],
                'volume': volumes[i]
            })
    return events
```

```python
def _classify_wyckoff_phase(self, symbol, lookback=150):
    bars = self.history(symbol, lookback, Resolution.DAILY)
    if bars is None or bars.empty or len(bars) < 50:
        return 'UNKNOWN'

    closes  = bars['close'].values
    volumes = bars['volume'].values

    # Identify recent trading range (last 60 bars)
    recent_hi = np.max(closes[-60:])
    recent_lo = np.min(closes[-60:])
    range_pct  = (recent_hi - recent_lo) / recent_lo

    current = closes[-1]

    # Must be in a trading range (not a strong trend)
    if range_pct < 0.05:
        return 'TIGHT_RANGE'   # too tight for Wyckoff analysis

    # Detect key events
    sc_events  = self._detect_selling_climax(bars, lookback=60)
    bc_events  = self._detect_buying_climax(bars, lookback=60)
    spring_evt = self._detect_spring(bars, support_level=recent_lo)
    sos_events = self._detect_sos(bars, resistance_level=recent_hi, lookback=60)
    ut_events  = self._detect_upthrust(bars, resistance_level=recent_hi)

    # Determine phase
    has_sc      = len(sc_events) > 0
    has_bc      = len(bc_events) > 0
    has_spring  = len(spring_evt) > 0
    has_sos     = len(sos_events) > 0
    has_utad    = len(ut_events) > 0

    # Price position within range
    pos_in_range = (current - recent_lo) / (recent_hi - recent_lo)

    if has_sc and not has_sos:
        if has_spring:
            return 'ACCUMULATION_SPRING'   # Phase C — strong buy setup
        elif pos_in_range < 0.35:
            return 'ACCUMULATION_EARLY'    # Phase B — wait
        else:
            return 'ACCUMULATION_LATE'     # Phase C/D — LPS area

    elif has_sos:
        if pos_in_range > 0.85:
            return 'MARKUP'               # Trend started
        else:
            return 'ACCUMULATION_SOS'     # BU opportunity

    elif has_bc and not has_utad:
        if pos_in_range > 0.65:
            return 'DISTRIBUTION_EARLY'   # Phase B — wait
        else:
            return 'DISTRIBUTION_LATE'    # Phase C/D — LPSY area

    elif has_utad:
        return 'DISTRIBUTION_UTAD'        # Short opportunity

    return 'TRENDING_OR_UNKNOWN'
```

```python
def _wyckoff_signal(self, symbol):
    phase = self._classify_wyckoff_phase(symbol)

    bars    = self.history(symbol, 150, Resolution.DAILY)
    closes  = bars['close'].values
    recent_hi = np.max(closes[-60:])
    recent_lo = np.min(closes[-60:])
    current   = self.securities[symbol].price

    if phase == 'ACCUMULATION_SPRING':
        # Spring confirmed — strong buy
        stop   = recent_lo * 0.97          # 3% below the spring low
        target = recent_hi * 1.05          # above the trading range
        return {'direction': 'LONG', 'stop': stop, 'target': target, 'phase': phase}

    elif phase == 'ACCUMULATION_SOS':
        # Back Up to broken resistance — buy the dip
        stop   = (recent_lo + recent_hi) / 2  # mid-range support
        target = recent_hi * 1.10
        return {'direction': 'LONG', 'stop': stop, 'target': target, 'phase': phase}

    elif phase == 'ACCUMULATION_LATE':
        # LPS — conservative long near support
        stop   = recent_lo * 0.97
        target = recent_hi
        return {'direction': 'LONG', 'stop': stop, 'target': target, 'phase': phase}

    elif phase == 'DISTRIBUTION_UTAD':
        # Upthrust — short opportunity
        stop   = recent_hi * 1.03
        target = recent_lo * 0.95
        return {'direction': 'SHORT', 'stop': stop, 'target': target, 'phase': phase}

    elif phase == 'DISTRIBUTION_LATE':
        # LPSY — short on weak rally
        stop   = recent_hi * 1.02
        target = recent_lo * 0.97
        return {'direction': 'SHORT', 'stop': stop, 'target': target, 'phase': phase}

    return None   # No signal

def _scan_wyckoff_signals(self):
    if self.is_warming_up or self._trading_halted:
        return

    for symbol in self.active_securities.keys():
        if symbol.security_type != SecurityType.EQUITY:
            continue
        if self.portfolio[symbol].invested:
            continue

        signal = self._wyckoff_signal(symbol)
        if not signal or signal['direction'] != 'LONG':
            continue

        entry = self.securities[symbol].price
        stop  = signal['stop']
        risk_per_share = abs(entry - stop)
        if risk_per_share == 0:
            continue

        risk_dollars = self.portfolio.total_portfolio_value * 0.01
        qty = int(risk_dollars / risk_per_share)
        max_qty = int(self.portfolio.total_portfolio_value * 0.10 / entry)
        qty = min(qty, max_qty)
        if qty <= 0:
            continue

        self.market_order(symbol, qty, tag=f"wyckoff-{signal['phase']}")
        self._wyckoff_stops[symbol]   = stop
        self._wyckoff_targets[symbol] = signal['target']
        self.log(f"Wyckoff LONG {symbol} | Phase={signal['phase']} "
                 f"| Entry={entry:.2f} Stop={stop:.2f} Target={signal['target']:.2f}")
```

```python
def _vsa_confirmation(self, bars, direction='LONG'):
    closes  = bars['close'].values[-5:]
    opens   = bars['open'].values[-5:]
    volumes = bars['volume'].values[-5:]
    avg_vol = np.mean(bars['volume'].values[-20:])

    if direction == 'LONG':
        # Look for No Supply: narrow spread, low volume on last down bar
        for i in range(len(closes)):
            is_down = closes[i] < opens[i]
            narrow  = abs(closes[i] - opens[i]) < np.mean(np.abs(bars['close'].values - bars['open'].values)) * 0.5
            low_vol = volumes[i] < avg_vol * 0.7
            if is_down and narrow and low_vol:
                return True   # No supply present — bullish VSA confirmation

    elif direction == 'SHORT':
        # Look for No Demand: narrow spread, low volume on last up bar
        for i in range(len(closes)):
            is_up   = closes[i] > opens[i]
            narrow  = abs(closes[i] - opens[i]) < np.mean(np.abs(bars['close'].values - bars['open'].values)) * 0.5
            low_vol = volumes[i] < avg_vol * 0.7
            if is_up and narrow and low_vol:
                return True   # No demand present — bearish VSA confirmation

    return False
```


================================================================================
WYCKOFF + SUPPLY & DEMAND INTEGRATION
================================================================================

  Wyckoff and S&D are complementary:
    - S&D identifies the ZONE (where price is likely to react)
    - Wyckoff identifies the PHASE (whether to buy or wait at that zone)

  Combined logic:
    1. Find a fresh S&D demand zone
    2. Confirm the underlying stock is in Wyckoff ACCUMULATION phase
    3. Enter on Spring or LPS event at or near the demand zone
    4. Volume must confirm (No Supply or Stopping Volume on approach)

```python
def _sd_wyckoff_combined_signal(self, symbol):
    # Check S&D zone proximity
    price     = self.securities[symbol].price
    sd_zones  = self._identify_demand_zones(symbol, lookback=120)
    near_zone = any(z['bottom'] * 0.99 <= price <= z['top'] * 1.01 for z in sd_zones)

    if not near_zone:
        return None

    # Check Wyckoff phase is accumulation
    phase = self._classify_wyckoff_phase(symbol)
    if phase not in ('ACCUMULATION_SPRING', 'ACCUMULATION_LATE', 'ACCUMULATION_SOS'):
        return None

    # Volume confirmation (No Supply)
    bars = self.history(symbol, 25, Resolution.DAILY)
    vsa_ok = self._vsa_confirmation(bars, direction='LONG')
    if not vsa_ok:
        return None

    # All three align — high-probability entry
    best_zone = sd_zones[0]
    return {
        'direction': 'LONG',
        'stop':   best_zone['bottom'] * 0.97,
        'target': best_zone['top'] + (best_zone['top'] - best_zone['bottom']) * 2.5,
        'phase':  phase,
        'confidence': 'HIGH'
    }
```


================================================================================
WYCKOFF KEY RULES SUMMARY
================================================================================

  W1.  NEVER buy in a distribution range — wait for markdown, then accumulation
  W2.  NEVER short in an accumulation range — wait for markup, then distribution
  W3.  Spring is the HIGHEST probability long entry — but wait for recovery confirmation
  W4.  UTAD is the highest probability short entry — wait for close back below resistance
  W5.  Volume MUST confirm the phase interpretation — no volume = no conviction
  W6.  Cause (range width) determines Effect (move size) — wider base = bigger trend
  W7.  LPS and LPSY are the safest re-entry points (lower risk, confirmed direction)
  W8.  Do NOT trade in Phase B (middle of accumulation/distribution) — just observe
  W9.  Use weekly chart for phase, daily for entry, 4H for precision timing
  W10. Combine with VSA: No Supply before SOS = highest conviction buy setup

  WYCKOFF PHASE CHEAT SHEET:
    Phase A — Stopping of prior trend (PS, SC, AR)
    Phase B — Building the cause (STs, range trading)
    Phase C — Test of supply/demand (Spring or UTAD) ← BEST ENTRY POINT
    Phase D — Trend resumes (SOS, LPS or SOW, LPSY) ← SECOND ENTRY POINT
    Phase E — Full markup/markdown (price leaves the range)
